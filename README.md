# Dynamic Memory Allocation Simulator

**Team Members:** Adarsh Rai (018), Daksh(210), Abhishek(075)  
**Course:** B.Tech CSE - Section C  
**Subject:** Operating Systems

## Description
A Python command-line simulator for three contiguous memory allocation methods:
- First Fit
- Best Fit
- Worst Fit

It accepts memory block sizes and process sizes, displays the allocated block for each process, and reports the remaining free memory.

## Requirements
- Python 3
- No external libraries

## Run
Open this folder in VS Code and run:

```bash
python main.py
```

## Files
- `main.py` - takes input and displays results
- `algorithms.py` - contains the three allocation algorithms
- `requirements.txt` - dependency note
